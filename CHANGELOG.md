# Changelog

What changes for people using Iconeer, by version. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and versions follow [Semantic Versioning](https://semver.org/).

## [Unreleased]

### Added

- **Open at Login** in the menu bar icon starts Iconeer with your Mac, so it keeps putting icons back after a restart.
- Failures are written to the system log, so a bug report can include them.

### Fixed

- When the list of customized apps can't be read, Iconeer leaves it as it is and says so, instead of replacing it with an empty one.

## [0.1.0] - 2026-10-18

### Added

- Changes app icons with icons from macOSicons.com, with your own API key, or with any PNG or ICNS file.
- Puts the icons back after apps update themselves, while Iconeer runs.
- In English and Brazilian Portuguese.
- Install with one Terminal command; see the README.
